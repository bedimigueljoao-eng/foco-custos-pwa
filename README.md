# FOCO Custos PWA

PWA offline e instalável para controlo financeiro pessoal.

## Publicar no GitHub Pages

1. Cria um repositório novo no GitHub.
2. Carrega todos os ficheiros deste pacote para a raiz do repositório.
3. Abre **Settings > Pages**.
4. Em **Build and deployment**, escolhe **Deploy from a branch**.
5. Seleciona a branch **main** e a pasta **/(root)**.
6. Guarda e aguarda o link do GitHub Pages.
7. Abre o link no Chrome ou Edge. Quando a PWA estiver pronta, usa o botão **Instalar FOCO Custos**. No iPhone, usa Partilhar > Adicionar ao ecrã principal.

## Estado inicial

A aplicação abre totalmente vazia: sem contas, saldos ou movimentos de exemplo.

## Segurança dos dados

Os dados ficam no navegador do dispositivo. Usa regularmente **Definições > Exportar** para guardar um backup JSON.
